Cómo funciona - Flujo completo que hablamos:
1. Subes Excel/CSV con números (10 dígitos) - Anti-baneo 900ms delay humano
2. Eliges plantilla aprobada META tiempo real (se carga de graph.facebook.com/v20.0/waba/templates)
3. Das Enviar → se crea campaña con historial JSON
4. Backend envía en background con pausa/continuar - cada mensaje chequea si está pausada
5. Si pausas, se queda en pausada y puedes continuar cuando quieras
6. Los que responden entran en 🟡 Bandeja amarilla automática con etiqueta respuesta_campana + Score IA 70-90
7. Asignas asesor a esos amarillas → embudo ventas → alarma recordatorio
8. Todo queda con origen_campana = ID campaña para filtrar amarillas por campaña
