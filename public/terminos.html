1. Objeto - Qué es KLIDO

KLIDO AVANZA CONSULTING es un CRM empresarial multiagencia diseñado para aprovechar la API oficial de Meta WhatsApp Business API. Permite gestionar múltiples agencias, conversaciones, clientes desde un solo lugar con automatización, IA, score caliente, bandeja amarilla, pausa/continuar campañas Excel, datos cliente completo, alarma recordatorio, embudo ventas, asignación asesores, llamadas desde número propio API (Gold) y Gmail masivo anti-baneo (Gold).

4. Configuración API 1 Vez por Agencia

Cada agencia configura 1 vez su Phone ID, WABA ID, META TOKEN EAAT... en CRM > Config API 1 vez. Sin cruce entre agencias (multiagencia certificada). Si no configura, usa ENV por defecto pero se recomienda configurar propio para evitar bloqueos. Validación: phone_id + waba_id obligatorios.

5. Campañas Excel + Pausa/Continuar + Plantillas META Tiempo Real + Amarillas Automáticas

Subes.xlsx,.xls,.csv,.txt con números 10 dígitos separados coma/salto línea. Eliges plantilla APPROVED tiempo real de graph.facebook.com/v20.0/{waba}/message_templates. Backend envía con delay 900ms anti-baneo, incrementa limite_usado, crea clientes con origen_campana = ID campaña. Puedes pausar con /api/campanas/:id/pausa y continuar con /api/campanas/:id/continuar en cualquier momento. Historial JSON con accion y fecha. Si campaña pausada, loop chequea pausada y break.

Bandeja amarilla automática: Webhook POST /webhook recibe mensajes entrantes, detecta from, busca agencia por phone_number_id, upsert cliente con etiqueta='respuesta_campana' + score 70 (si pregunta precio/cuanto/precio/pago/interesa → score 90 caliente), ultimo_mensaje NOW(), leido false. Aparece arriba en bandeja con borde amarillo left 4px #eab308.

6. Datos Cliente Completo + Embudo + Alarma Recordatorio + Asesores

Por cada cliente: nombre, teléfono, email, datos JSONB, etiqueta (nuevo, respuesta_campana amarilla, caliente 🔥, frio, vendido), estado_embudo (nuevo, contactado, cotizado, cerrado), recordatorio TIMESTAMP con alarma cada 60s + Notification API, asesor_id asignado, score 0-100, origen_campana, notas, direccion. Guardado en /api/clientes/:id/datos. Leads de campaña se asignan a asesores (tabla asesores). Si score>80 IA recomienda asignar asesor.

7. IA Score Caliente (Premium/Gold)

Endpoint /api/ia/responder analiza texto: si contiene cuanto|precio|pago|interesa|comprar → score 90 etiqueta caliente, si hola|info|informacion → 65 respuesta_campana, si no|gracias → 10 frio. Actualiza cliente score y etiqueta. Solo disponible si plan.ia true, sino retorna 403 upgrade 3133181851.

8. Gmail Masivo Anti-Baneo (Gold)

POST /api/gmail/campana con asunto, html, destinatarios[], remitentes[] rotación. Envía con nodemailer gmail, delay 1200-3000ms aleatorio humano anti-baneo, logs en tabla logs_gmail con estado enviado/fallido. Solo plan.gmail true. Si no, 403.

9. Llamadas desde tu Número API (Gold)

POST /api/llamada con telefono, mensaje. Usa phoneIdEfectivo de agencia (su número oficial). Requiere permiso Calling API habilitado en su WABA en developers.facebook.com. Solo plan.llamadas true.
