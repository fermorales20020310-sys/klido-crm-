3. Protección de datos - Ley 1581 Habeas Data Colombia

Cada agencia es Responsable del Tratamiento de los datos de sus clientes que sube vía Excel. KLIDO actúa como Encargado, datos cifrados, segregados por agency_id, no se comparten entre agencias. Historial con fines de auditoría. Titular puede ejercer derechos vía agencia. Implementamos medidas antibaneo: envíos por bloques de 50 contactos cada 5 horas + 3 segundos entre mensajes para cuidar reputación del número. Punto amarillo identifica campañas en inbox. Ver Política de Privacidad completa.

4. Campañas - Excel auto detección + Plantillas aprobadas API

La agencia debe contar con plantillas aprobadas en Meta Business Manager. KLIDO sincroniza automáticamente solo plantillas aprobadas vía API oficial. La agencia es responsable de contar con autorización de contactos.
