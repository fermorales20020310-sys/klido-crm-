📢 Subir Campañas

Cómo se ejecuta:

1. Vas a Campaigns en el menú.
2. Excel con col A = número WhatsApp, col B = nombre.
3. Subes Excel + plantilla aprobada por Meta.
4. KLIDO envía 1 cada 8 seg anti-bloqueo.
Ventaja: envíos masivos, segmentados, medibles.

👥 Info de Contactos

Cómo se ejecuta:

1. Cada chat que entra se guarda automático en Inbox.
2. Se guarda: nombre, teléfono, etiqueta (nuevo/interesado/cita), último mensaje.
3. Click en contacto > ves historial completo.
Ventaja: base centralizada sin perder chats.

🔌 Historial API WhatsApp

Cómo se ejecuta:

1. KLIDO usa WhatsApp Business API oficial.
2. Cada mensaje queda logueado con hora, estado (entregado/leído).
3. Si API se cae, alerta aquí.
Ventaja: trazabilidad total, cero perdidos.

✅ Plantillas API Aprobadas

Cómo se ejecuta:

1. Creas plantillas en Meta Business Manager.
2. Meta aprueba en 24h.
3. KLIDO solo permite usar aprobadas.
Ventaja: evitas bloqueos, 100% Meta.

🤖 IA Automática - Exclusivo Gold

Solo Plan Gold - Incluye pánico humano y llamada directa

Cómo se ejecuta:
1. Activas IA y escribes tu Prompt (ej: "Eres asesor KLIDO, responde amable y agenda citas").
2. Cuando entra WhatsApp, IA responde sola en 3 seg.
3. Si cliente escribe "humano/asesor/llamar" → IA entra en pánico humano y te asigna el chat.
4. En Gold incluye llamada directa desde el chat.
Ventaja Gold: atención 24/7, solo intervienes cuando es necesario.
